03Backend MockVerifica chave de confiança

O navegador acessa o Gateway por HTTPS. O Gateway verifica a requisição e, quando autorizado, encaminha os pedidos para o backend local. A demonstração de acesso sem confiança é realizada pelo Gateway no servidor, pois o navegador não pode ler livremente respostas de outra origem sem CORS.

Projeto acadêmico • Credenciais, segredo compartilhado e certificado são apenas de desenvolvimento. Não use estes valores em produção.
